# Тула.Транспорт

> AI-ассистент для пассажиров общественного транспорта Тульской области.

**Тула.Транспорт** — интерактивный прототип первой линии поддержки. Он отвечает на вопросы пассажиров об оплате, льготах, абонементах, валидаторах и списаниях, показывает источник ответа и передаёт сложные случаи оператору. В интерфейс также встроена карта общественного транспорта: просмотр линий и построение поездки между двумя точками.

## Что умеет прототип

- Отвечает на типовые обращения пассажиров по локальной базе знаний.
- Работает в двух режимах: **онлайн с GigaChat** и **офлайн без внешней модели**.
- Не придумывает ответы: если подтверждённых данных нет, предлагает уточнить вопрос или обратиться в ОЕИРЦ.
- Показывает источник и ссылку для справочного ответа, когда они есть.
- Поддерживает разговорные и переформулированные вопросы в онлайн-режиме.
- Позволяет открыть полный список тестовых шаблонных запросов.
- Строит поездку **A → B** на общественном транспорте через 2ГИС, включая пересадки, остановки и доступное расписание.
- Показывает направления маршрутов на карте 2ГИС с геометрией улиц и остановками.
- Ищет остановки по названию, адресу или обычной пользовательской формулировке.
- Показывает доступные маршруты на выбранной остановке.

## Интерфейс

Проект оформлен в визуальном стиле мессенджера MAX: компактный адаптивный чат, единый радиус скруглений, светлая цветовая система и мобильная адаптация. В левой панели находятся демонстрационная кнопка «Цифровой ID в MAX» и ссылки на партнёров проекта.

## Технологии

| Задача | Решение |
| --- | --- |
| Интерфейс | HTML, CSS, JavaScript, один автономный веб-интерфейс |
| Локальный сервер | Python, `ThreadingHTTPServer` |
| AI-режим | GigaChat API |
| Карта и поездка A → B | 2ГИС MapGL и Routing API |
| Геометрия отображаемых линий | Локальная выгрузка `tula-route-geometry.json` |
| Офлайн-ответы | Встроенная база подтверждённых материалов |

## Быстрый запуск

### 1. Установите Python

Нужен Python 3.10 или новее. Проверить установку можно командой:

```powershell
python --version
```

### 2. Запустите приложение

В папке проекта дважды нажмите:

```text
start-prototype.cmd
```

Скрипт запускает локальный сервер. Затем откройте в браузере:

```text
http://127.0.0.1:8771/
```

Если порт уже занят старой версией сервера, скрипт предложит завершить именно этот локальный процесс и запустить актуальную версию.

## Настройка GigaChat

Онлайн-режим необязателен: без него помощник продолжает отвечать по офлайн-базе.

1. Получите `Authorization Key` в кабинете GigaChat с нужным scope, например `GIGACHAT_API_PERS`.
2. Запустите проект и нажмите **«Настроить GigaChat»**.
3. Вставьте ключ в открывшееся поле и сохраните настройку.
4. Переключите режим чата на **«Онлайн · GigaChat»**.

Ключ хранится только во время работы локального сервера. Не добавляйте его в исходный код, `.env` без защиты или репозиторий.

При недоступности GigaChat приложение автоматически сообщает о проблеме и может быть переведено в офлайн-режим.

## Настройка карты 2ГИС

Для карты и построения маршрутов нужен ключ 2ГИС MapGL/Routing API.

1. Получите ключ в [2ГИС Platform Manager](https://platform.2gis.com/).
2. В интерфейсе карты укажите ключ 2ГИС в настройке, если приложение его запросит.
3. Откройте **«Карта и маршруты»**.

Режимы карты:

- **Маршруты** — выберите вид транспорта, найдите номер, отметьте одно или несколько направлений и нажмите «Показать на карте».
- **Поездка A → B** — введите остановки/адреса либо отметьте точки прямо на карте; сервис найдёт оптимальный вариант общественным транспортом.

## Источники и ограничения

- **2ГИС** используется как базовая карта и сервис построения поездок A → B.
- В репозитории хранится локальная выгрузка геометрии маршрутов. Для промышленного подключения РНИС ТО её следует заменить на официальную выгрузку или API РНИС ТО в формате GTFS/GeoJSON.
- Прототип не обрабатывает персональные данные и не заменяет проверку оператором.
- По вопросам, требующим проверки конкретной поездки, карты или списания, пассажиру следует обратиться в ОЕИРЦ: **+7 (4872) 705-507**.
